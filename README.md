# 💫 About Me

Backend Developer specializing in Python, Django, and FastAPI ecosystems. Experienced in designing **schema-based multi-tenant SaaS architectures**, high-performance API Gateways, RESTful APIs, and automated containerized deployment pipelines using Docker and Linux.

Skilled in PostgreSQL, Redis, Celery, Git, and GitHub Actions for CI/CD workflows, with a strong passion for writing clean, maintainable, and highly scalable code while continuously adopting modern backend technologies.

---

## 💡 Core Competencies & Architecture

* **Multi-Tenant SaaS Architectures:** Schema-based multi-tenancy using PostgreSQL `search_path` dynamic routing for strict data isolation and scalable data management.
* **API Gateways & Microservices:** Building high-speed, asynchronous reverse proxies with FastAPI for route caching, token validation, and dynamic proxying.
* **Database Management & Migrations:** Executing programmatic, isolated schema-level migrations via dedicated microservices (Flask / Django ORM).
* **DevOps & Release Engineering:** Container lifecycle management, immutable Docker image registries, shell automation, and production deployment flows.
